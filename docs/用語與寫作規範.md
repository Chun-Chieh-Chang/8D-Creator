# 用語與寫作規範

本專案採用 ASD-STE100 Issue 9 的寫作原則。英文採務實模式。繁體中文沿用短句、主動語態與一致術語。保留 8D、CAPA、RPN、API 等領域名稱。

參考 [ASD-STE100 Issue 9](https://www.asd-ste100.org/about_STE.html) 和 [JAICHANGPARK/ASD-STE100 的務實模式](https://github.com/JAICHANGPARK/ASD-STE100/tree/384d7d568da6f55ee379e429f9b4e1b0bd603536)。

## 撰寫與檢查

1. 每句寫一個重點。用主動語態說明誰做什麼。
2. 每個操作步驟寫一個動作。用動詞開始，例如「選取『匯出 PDF』」。
3. 按鈕用「動詞＋對象」。欄位用名詞。錯誤訊息先說明狀態，再說明下一步。
4. 英文操作句最多 20 個單字。英文說明句最多 25 個單字。使用美式拼字。
5. 開發更新先寫目的，再記錄決策、已完成工作和待處理事項。保留原始錯誤訊息與識別碼。
6. 新增術語時先更新術語表。若需要防止舊寫法重現，更新術語檢查規則。
7. 執行 `npm run lint:terms`。人工檢查主動語態、語意與步驟順序。

術語檢查會回報專案內選定的用詞差異。英文句型與正式字典用法由人工審查。既有報告、歷史變更紀錄及外部來源引文保留原文。
